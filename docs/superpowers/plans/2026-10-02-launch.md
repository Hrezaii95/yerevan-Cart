# Yerevan Cart Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Execute locally with one independent final review.

**Goal:** Publish a functional public trilingual comparison app with authenticated cloud saves and ChatGPT tools.
**Architecture:** React/Vinext UI, pure deterministic model, D1-backed user records, stateless MCP endpoint. Sites manages identity and hosting.
**Tech Stack:** TypeScript, React, Vinext, Cloudflare D1, Drizzle schema/migrations.
**Spec:** ../specs/2026-10-02-launch-design.md

## Global constraints
- English, Armenian, Russian at equivalent functional depth.
- Missing costs never become zero or a qualified winner.
- No payment or marketplace connection claim without a real configured service.
- Public pages; authenticated owner-scoped storage and MCP data tools.

## Review focus
- Hostile imported URLs/text: validate, render as text, no server fetch.
- Cross-account read/delete: every query constrained by user ID.
- Null versus zero freight: unknown subtotal cannot win.
- Oversize/invalid input and duplicate save: bounded validation and idempotent IDs.
- Language switch and saved-record reopening: preserve current data.
